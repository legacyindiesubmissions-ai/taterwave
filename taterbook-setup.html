TaterBookBuilder Setup Guide

  1. Download the latest AppImage from the product page.
  2. Make it executable: chmod +x TaterBookBuilder-x86_64.AppImage
  3. Run the application: ./TaterBookBuilder-x86_64.AppImage
  4. On the first run, navigate to the Setup tab.
  5. Enter your API keys for your preferred LLM provider.
  6. Enter your License Key to unlock full ingestion and export capabilities.
