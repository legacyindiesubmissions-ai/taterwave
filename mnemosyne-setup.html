Mnemosyne Setup Guide

This guide will help you activate your Mnemosyne license and connect it to your AI client (Claude Desktop, Cursor, or Windsurf).

1. Download & Place Binary

First, download the server binary for your operating system:

  • Windows: Mnemosyne.Server.exe
  • Linux: Mnemosyne.Server
Important: Move the file to a permanent folder (e.g., C:\Tools\ or /home/user/bin/). If you leave it in your Downloads folder and delete it later, Mnemosyne will stop working.

2. Configuration (Claude Desktop)

You need to edit your claude_desktop_config.json file.

File Locations:

  • Windows: %APPDATA%\Claude\claude_desktop_config.json
  • Mac: ~/Library/Application Support/Claude/claude_desktop_config.json

Windows Setup:

Windows paths MUST use double backslashes \\.

{ "mcpServers": { "mnemosyne": { "command": "C:\\Tools\\Mnemosyne.Server.exe", "args": [ "--license-key", "MNEM-YOUR-KEY-HERE" ] } } }

Mac / Linux Setup:

{ "mcpServers": { "mnemosyne": { "command": "/home/username/bin/Mnemosyne.Server", "args": [ "--license-key", "MNEM-YOUR-KEY-HERE" ] } } }

3. Configuration (Cursor)

  • Open Cursor Settings (Ctrl+Shift+J).
  • Go to Models -> MCP.
  • Click + Add New MCP Server.
  • Name: mnemosyne
  • Type: command
  • Command: C:\Tools\Mnemosyne.Server.exe --license-key MNEM-YOUR-KEY-HERE

4. Troubleshooting

"Invalid license key"

Ensure your key starts with MNEM-. Check for trailing spaces if you copy-pasted.

"Command not found" or "Pipe closed"

This usually means the path in your config is wrong. Windows users, double check the \\ characters.

How do I know it's working?

Restart your AI client and ask it: "Can you check your Mnemosyne memory state?"
